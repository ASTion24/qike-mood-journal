# 栖刻

一个私密、轻量的情绪日记与自我关怀 Web 原型。

在线访问：**https://astion24.github.io/qike-mood-journal/**

## 功能

- **日记**：纸页式书写区与最近记录并排；情绪、强度和可选文字，草稿自动保存，触发线索需由用户确认
- **回顾**：7 / 14 / 30 天按实际日期展示感受与强度；完整日记可搜索、筛选、编辑和删除
- **练习**：依据最近记录推荐呼吸、感官着陆、步行或环境和音；练习支持暂停、完成反馈和历史回顾
- **数据自主**：示例与个人记录分开；JSON 导出、合并恢复、单条/全部删除、旧版数据迁移
- **可访问性**：手机适配、键盘操作、弹窗焦点管理、减少动态效果偏好、即时支持入口

## 产品取舍

不要求登录，只选情绪也能保存。示例让初次访问者了解产品，但不混入个人统计。

界面以纸白、墨灰和少量蓝色组织信息。首页直接进入书写，使用日期和日记内容建立层级；桌面采用横向导航，手机采用固定底部导航。动画仅用于操作反馈和正在进行的练习。

分析使用设备内的关键词和统计规则，未调用大模型或提供医疗诊断。文字里出现一个词不代表它是原因，因此待确认线索不会自动计入统计。图表保留每次记录，不把不同情绪平均成一个好坏分数。

数据仅保存在当前浏览器的 `localStorage` 中，无账号同步或服务器备份。更换设备前应手动导出；清理浏览器数据会删除记录。此原型适合个人使用，不是紧急援助服务。

所有脚本与图标随站点托管，音频由 Web Audio 生成，无第三方运行时请求。

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

## 回归验证

安装 Python Playwright 与 Chromium 后，启动独立服务并运行：

```bash
python3 -m http.server 43127 --bind 127.0.0.1
# 在另一个终端中
python3 tests/ui_smoke.py
```

测试覆盖数据隔离、草稿恢复、线索确认、历史编辑、备份去重与无效文件、旧数据迁移、存储失败、练习计时/反馈，以及 320–1440px 的五种屏宽。截图写入被 Git 忽略的 `artifacts/`。
